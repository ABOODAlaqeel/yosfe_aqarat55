# بنية وتصميم الواجهات (Frontend UI Structure)

تصميم تطبيق "إدارة العقارات" سيعتمد على الواجهات التالية التي ستتكون بشكل أساسي منها:

## 1. لوحة التحكم (Dashboard Screen)

- **الغرض:** عرض الحالة العامة للعقارات.
- **المكونات:**
  - بطاقة: إجمالي العمارات المضافة.
  - بطاقة: إجمالي الشقق في كل العمارات، عدد المؤجر منها والفارغ.
  - بطاقة: إحصائية للمستأجرين الذين دفعوا والليس بعد.
  - التنقل: قائمة سفلية (Bottom Navigation Bar) للتنقل بين (الرئيسية، العمارات، المستأجرين).

## 2. إدارة العمارات (Buildings Management)

### أ. شاشة العمارات (Buildings Screen)

- **الغرض:** جدول أو بطاقات تعرض قائمة العمارات المسجلة.
- **التفاعل:** زر عائم (FAB) لإضافة عمارة جديدة.
- **عند النقر على عمارة:** يتم فتح صفحة **تفاصيل العمارة**.

### ب. نافذة إضافة عمارة منبثقة/شاشة (Add Building Form)

- **الحقول:** اسم العمارة / رقمها.
- **الحقول:** عدد الطوابق (إدخال رقمي).
- **الحقول:** عدد الشقق الإجمالي.
- **نظام الإيجار:** تحديد هل الإيجار (شهري / سنوي) عبر خيارات زر.
- **اختيار التسمية:** هل تريد ترقيم الشقق تلقائياً (مثل: طابق ١ - شقة ١٠١) أم تسجيل أسماء الشقق يدوياً بصيغة مفتاح تبديل (Switch).

## 3. تفاصيل العمارة (Building Details Screen)

هذه الشاشة مقسمة إلى تبويبتين رئيسيتين (Tabs)، وتحتوي على زر إجراءات عائم (FAB) متمدد يظهر خيارين عند النقر عليه: "إضافة مستأجر" و"دفع الإيجار" لتسهيل الوصول للأوامر المتعلقة بهذه العمارة، مع العلم أن هذه الأزرار تقوم بتحديد اسم العمارة تلقائياً في النوافذ المنبثقة.

### التبويبة الأولى: الشقق (Apartments Tab)

- **المحتوى:** شبكة (Grid) أو بطاقات تعرض جميع شقق العمارة.
- **البيانات واللون:** الأخضر للشقق الفارغة، والأحمر للشقق المؤجرة.
- **نافذة الإضافة المنبثقة (Add Tenant Modal):**
  - **قائمة منسدلة للعمارة:** إذا تم الفتح من تفاصيل عمارة معينة، يتم تحديدها تلقائياً وإلغاء الحاجة لاختيارها مرة أخرى.
  - **قائمة الشقق:** اختيار شقة (تظهر فقط الشقق الفارغة في هذه العمارة).
  - **بيانات المستأجر:** الاسم، رقم الهاتف، مبلغ الإيجار المتفق عليه، وملاحظات (اختياري).
  - **المرفق:** زر لإرفاق صورة لعقد الإيجار (كاميرا/معرض).

### التبويبة التانية: المستأجرين في العمارة (Tenants Tab)

- **المحتوى:** قائمة (ListView) تعرض جميع مستأجري العمارة والمبلغ المطلوب منهم.
- **حالة الدفع:** أيقونة أو علامة (تم الدفع / لم يتم الدفع).
- **التفاعل:** الضغط على اسم المستأجر ينقل لصفحة "تفاصيل المستأجر".
- **الدفع (النافذة المنبثقة):**
  - **قائمة العمارة والمستأجر:** إذا لم يتم الفتح من عمارة مسبقة تحديدًا يمكن اختيار العمارة، يليه قائمة ذكية تعرض (المستأجرين الذين لم يدفعوا لهذا الشهر). وهناك خيار لـ "عرض الكل". إذا فُتحت النافذة من مِلف مستأجر، يتم تجهيز النافذة باسمه مباشرة دون قوائم منسدلة.
  - **المدة:** إمكانية الدفع لشهر واحد عبر اختيار التاريخ من التقويم (Date Picker)، أو تحديد "الدفع لعدة أشهر متصلة" عبر مفتاح تبديل يسمح بتحديد "من شهر X" "إلى شهر Y"، ليقوم بضرب الإيجار تلقائياً في عدد الأشهر.
  - **حقل مبلغ الإيجار:** يُحسب تلقائياً أو يتم تغييره.
  - **طريقة الدفع:** قائمة (نقدي/حوالة/شيك).
  - **ملاحظات:** حقل اختياري لإضافة تفاصيل.

## 4. تفاصيل المستأجر (Tenant Details Screen)

هذه الشاشة مقسمة لتبويبتين (Tabs) لكي تحتوي ملف المستأجر كاملاً، كما توفر زر دفع إيجار عائم يقوم مباشرةً باستدعاء نافذة (PaymentDialog) مع تحديد بيانات المستأجر مسبقاً، مما يختصر خطوة البحث.

### التبويبة الأولى: البيانات الشخصية (Profile Tab)

- **المحتويات:**
  - اسم المستأجر (يمكن إضافة أيقونة/صورة رمزية).
  - الشقة، واسم/رقم العمارة المستأجر بها.
  - مبلغ الإيجار الإجمالي.
  - مرفق (صورة عقد الإيجار) يمكن النقر عليها لتكبيرها.

### التبويبة الثانية: تفاصيل الدفع (Payment History Tab)

- **المحتويات:** قائمة بمدفوعات هذا المستأجر التاريخية (مثال: دفع 50 ألف ريال لشهر يناير يوم 1، دفع 50 ألف ريال لشهر فبراير يوم 2... إلخ).
- مجموع المدفوع كإجمالي إن لزم ذلك.
